# Overview

Mana Vault is a self-hosted Magic: The Gathering collection and deck manager for one household or a small group, run on your own server and used from a desktop browser or a phone.

| Area | What it holds |
|---|---|
| **Card search** | The full local card database: every printing, searchable by name, type, rules text, color, set, rarity, legality and mana value |
| **My collection** | The printings you own, with a count of regular and foil copies for each |
| **Decks** | Your decks, each with a format, a mode (Normal or Theme) and cards in the main deck, sideboard or commander zone |
| **Card database** | The local copy of the card catalog that search, imports and decks match against |

Card search is where cards are found. From a search result a card is added to the collection, to the open deck, or both. Imports and the camera scanner feed the same search and matching rules.

## Principles

1. **Your data stays on your server.** The collection, decks and accounts are stored in one database file in the server's data folder. Only card images and the card catalog download come from outside.
2. **Portable formats.** Collections export as Moxfield-compatible CSV, decks as plain text or CSV, and the whole library as a readable JSON backup.
3. **Every change shows its result.** Lists redraw at once and a short confirmation appears in the status bar.
4. **Mistakes are easy to reverse.** Collection and deck edits can be undone and redone.
5. **Keyboard first on the desktop, touch first on the phone.** Every common command has a shortcut, and the phone layout uses large touch targets.
