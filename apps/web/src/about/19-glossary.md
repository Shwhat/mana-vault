# Glossary

| Term | Meaning in Mana Vault |
|---|---|
| Card | A card by name, such as Lightning Bolt, across all its printings |
| Printing | One version of a card in one set, with its own set code, collector number, rarity and artwork |
| Card database | The local catalog of every printing, downloaded from Scryfall |
| Collection | A named place for cards you own, such as a binder, with its own rules for set completion |
| Collection entry | One printing in one finish, condition and language in a collection, with a count and a number for trade; also called a row |
| Finish | Regular, foil or etched. Etched is a foil-like finish printed on some cards; it counts as foil for set completion |
| Condition | How worn a copy is: Mint, Near mint, Lightly played, Moderately played, Heavily played or Damaged |
| Copy details | The window that changes a row's finish, condition, language and number for trade |
| Wishlist | A collection of cards you want. Its cards do not count as owned |
| Trade list | Every copy marked for trade in the collections you own |
| Trade calculator | The two sides, You give and You get, that compare the value of a trade |
| Price | Scryfall's price for a printing on the day of the last card database update |
| Value | Price times count, added up for a row, collection or deck |
| Currency | US dollars or euros, the unit for every price and value on screen |
| Filter tag | A narrowing of the collection list chosen by clicking a set code, rarity or Statistics bar |
| Binder layout | The collection shown as pages of nine card images |
| Flavor name | Another name printed on some versions of a card, matched by search and imports |
| Ownership | Which deck cards you own across your collections |
| Target collection | The collection that Add to collection puts cards into |
| Open collection | The collection shown in the collection view |
| Linked set | A set whose completion a collection tracks |
| Completion rule | Main set, Every printing or Each card name once; decides which cards a linked set needs |
| Finish rule | Any finish, Regular only, Foil only or One of each; decides which finishes count |
| Printed size | The number of numbered cards printed in a set, from Scryfall's set list |
| Picked rows | Collection rows chosen for a bulk move or remove |
| Owner | The account an item belongs to |
| Offer | A collection or deck sent to another account, waiting in their Inbox |
| Copy, Share, Transfer | The three ways to send: their own copy, one item you both edit, or moving it to them |
| Inbox | The list of offers waiting for you and offers you sent |
| Foil | The shiny finish of a printing. Regular and foil copies are counted separately |
| Deck | A named list of cards with a format and a mode |
| Normal mode | A deck mode that keeps cards by name, so any printing counts |
| Theme mode | A deck mode that keeps the exact printing of each card |
| Zone | Where a card sits in a deck: main deck, sideboard or commander |
| Target zone | The zone that Add to deck puts cards into |
| Scanned list | Cards recognized by the scanner or added by name, waiting on this device to be added to a collection or deck |
| Information line | The small text at the bottom left of a card printed since 2019, with the collector number, rarity letter, set code and language |
| Open deck | The deck that Add to deck, the Deck list panel and the deck view work with |
| Format | A deck's label (Commander, Standard and so on). Mana Vault does not check format rules |
| Mana value | The total mana in a card's cost, used by the mv filter |
| Color identity | Every color in a card's cost and rules text, used by the id filter |
| Selected card | The row last clicked or moved to with Up and Down; its details show in the Card panel |
| Panel | A dockable window beside the work area: Filters, Collections, Decks, Card, Deck list or Import review |
| Workspace | A saved arrangement of panels and a view |
| Ribbon | The tabs of buttons under the menu bar |
| Contextual tab | A ribbon tab shown only when it applies; the amber Deck tab appears while a deck is open |
| Import preview | The check of an import file that shows what would be added before anything changes |
| Backup | A JSON file with one account's own collections, decks and the card records they use |
| Session | A signed-in browser, kept for 30 days |
