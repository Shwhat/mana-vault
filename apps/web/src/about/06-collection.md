# Collection

The collection records which printings you own and how many regular and foil copies of each.

## Collection entries

Each entry is one printing in one finish. The same printing can have two entries: one regular and one foil.

| Field | Type | Notes |
|---|---|---|
| Card | Printing | The exact set and collector number |
| Foil | Yes or no | Set by **Add as foil** at the time of adding, or by the Foil column of an import |
| Count | Whole number from 1 to 10,000 | A count that would drop below 1 removes the entry |

## Adding cards

1. Select a printing in the card search.
2. Press Enter, choose **+ Collection**, double-click the row, or use **Add to collection**.
3. One copy is added. If an entry for that printing and finish exists, its count goes up by one; otherwise a new entry is made.

**Add as foil** decides the finish. It is off by default and stays as you leave it, for your account. Switch it with **F**, the FOIL item in the status bar, the Home ribbon tab or the Cards menu.

## The collection view

Press **2** (or **Collection**) to open it. Each row shows the card image, name, a FOIL badge for foil entries, set, collector number, rarity, the count with minus and plus buttons, and a remove button.

- The filter box keeps rows whose card name, set name or set code contains the text.
- The header shows the number of entries shown and the total number of cards in the collection.
- Minus at a count of 1 removes the entry, the same as the remove button.

## Owned counts

The Card panel's Owned group shows, for the selected printing, the regular and foil copies you own, and under All printings the total copies of every printing of the same card.

## Undo

Adding, changing a count and removing can be undone with Ctrl+Z and redone with Ctrl+Y. See [Settings and shortcuts](/about/settings-and-shortcuts).
