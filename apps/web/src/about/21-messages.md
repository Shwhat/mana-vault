# Messages

Messages appear at the right end of the status bar (on the phone, in a banner above the tabs). Confirmations are blue and disappear after a few seconds. Problems are red and stay for about seven seconds. Messages specific to search, scanning, the card database, accounts, Administration and backups are listed on those pages: [Card search](/about/card-search), [Scanning cards](/about/scanning-cards), [Card database](/about/card-database), [Accounts and access](/about/accounts), [Administration](/about/administration) and [Storage and backups](/about/storage-and-backups).

## Rows skipped by an import

These reasons appear in the import preview and the Import review panel.

| Reason | Cause |
|---|---|
| Card name is empty | The row has no card name |
| Quantity must be a whole number from 1 to 10,000 | Collection row count is not valid |
| Quantity must be a whole number from 1 to 100 | Decklist row count is not valid, or a text line has no count |
| Unrecognized foil value "x" | The Foil column holds something other than the accepted values |
| Unrecognized condition "x" | The Condition column holds something other than the accepted values |
| Unrecognized language "x" | The Language column holds an unknown language |
| Tradelist count must be a whole number of 0 or more | The Tradelist Count column is not a whole number |
| No card with this name exists in the card database | The name does not match any card; check the spelling or update the card database |
| No printing matched set number | No printing has that set and collector number |
| No printing matched the supplied set and collector number | The same, for decklists |
| Theme decks need both a set and collector number | A Theme deck row has no exact printing |
| Zone must be Main, Sideboard, or Commander | The Zone column holds an unknown value |
