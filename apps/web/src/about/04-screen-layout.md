# Screen layout

On screens 900 pixels wide or more, Mana Vault uses the desktop layout described first. Narrower screens use the phone layout described at the end.

## Desktop layout

From top to bottom: the title bar with the menus, the mode tabs, the main area (panels around the work area), and the status bar.

## Title bar and menus

The title bar shows the program name, the server name when one is set in Administration, the **File**, **Edit**, **View** and **Help** menus, the name of the open deck, and the account menu on the right (your user name). An amber count beside your user name shows offers waiting in your Inbox. The account menu holds **Inbox...** (with the number waiting), **Change password...**, **Devices...**, **Administration...** (admins only, see [Administration](/about/administration)), every workspace (such as Deck building workspace, checked when in use), **Save workspace...**, **Manage workspaces...**, **Reset panels** and **Sign out**.

Click a menu to open it. While a menu is open, pointing at another menu opens that one. Each command shows its shortcut on the right, and a check mark shows a choice that is on. Esc or a click elsewhere closes the menu. A command that cannot be used right now is not shown.

| Menu | Commands |
|---|---|
| File | New collection..., New deck..., Import..., Export..., Export purchase history... (Export purchases), New purchase..., New card sale... or Sell selected cards... when cards are picked in a collection (Sell), Scan card..., Download backup, Restore backup..., Update card database (Update database, admins only), Sign out |
| Edit | Undo, Redo, Find, Select all cards, Clear filters |
| View | Purchases view (Purchases); Light theme, Dark theme, System theme; Prices on pictures; Card layout...; Filters panel, Collections panel, Decks panel, Card panel, Deck list panel, Import review panel |
| Help | Keyboard shortcuts, About Mana Vault |

Undo and Redo show the change they will reverse or repeat, for example "Undo Add Sol Ring". The same two commands are arrow buttons in the title bar right after the Help menu (and in the phone's top bar): the tooltip names the change, such as "Undo Add Sol Ring (Ctrl+Z)", and a button is greyed out when there is nothing to undo or redo. **Import...** and **Export...** open the import and export windows; see [Import and export](/about/import-and-export).

## Mode tabs

Under the title bar, the mode tabs switch the program between its parts. The tab of the part in use is highlighted.

| Tab | Opens | Key |
|---|---|---|
| Home | The Home view (Home) | |
| Search | Card search (Card search) | 1 |
| Collection | The open collection (Collection view) | 2 |
| Decks | The open deck (Deck view) | 3 |
| Trade | Trades (Trade view), with a count when trades wait for your answer | 4 |
| Proxies | The print list and the card maker (Proxies view) | 5 |
| Purchases | Purchase history (Purchases view); see [Purchases](/about/purchases) | 6 |

The views of a collection (Cards, Completion, Missing, Statistics) and of a deck (Cards, Ownership, Statistics, Playtest, Description, History) are the tabs in the header of that view.

## Right-click menus

Right-clicking a card, a collection or a deck opens a menu of what can be done with it. On a phone, a long press (half a second) opens the same menu; moving the finger cancels it.

| Item | Menu |
|---|---|
| Search result | Card page, Add to name... (where cards go), Add as proxy, Add to wishlist, Add to print list |
| Collection entry, grid card or binder pocket | Card page, Copy details..., Change printing..., Move..., Mark for trade or Unmark for trade, Add to the open deck, Add to print list, Reduce to 1 (more than one copy), Remove |
| Deck card, in any view and in the Deck list panel | Card page, Change printing..., Link copies..., Link owned copies and Switch to the version owned... (for missing cards you own), Mark as upgrade wanted... or Change upgrade wanted... and Remove upgrade wanted mark, Tags..., Move to each other zone, Use as cover card, Add missing to wishlist (when cards are missing), Add to print list, Reduce to 1 (more than one copy), Remove from deck |
| Collection, in the Collections panel or the collection switcher | Open, Rename..., Collection settings..., Send..., Export..., Delete (Leave for a collection shared with you). Rename, settings and Send are only for your own collections |
| Deck, in the Decks panel or the deck switcher | Open, Rename..., Deck format..., Add deck to collection..., Send..., Export..., Delete (Leave for a deck shared with you). Rename, format and Send are only for your own decks. Deck format and Export open the deck first |

**Change printing...** opens the printing chooser: every printing of the card, newest first, with its picture, set, number and year, a button with the price for each finish the printing is made in (**Regular**, **Foil**, **Etched**), and a box to find a set, code or number. The current printing shows **Current** with its finish, and its finish button is highlighted. Choose a finish button to switch to that printing in that finish, such as the foil version of the current printing. Clicking a printing, or pressing Enter on it, chooses it in the finish in use (or its first finish when it is not made in that one). For a collection entry or deck card with more than one copy, **How many to change** at the top sets how many copies change (all by default). The same chooser, titled "Version wanted for card", picks the version for **Mark as upgrade wanted...**, and, titled "Add card to name", the printing and finish to add, with the printing shown selected so Enter takes it. Special foils show their name on the finish button and the Current mark, such as **Surge foil**.

Commands that can be used are shown in the normal text color.

## Work area

The work area in the middle shows one of six views, chosen with the Views group on the Home tab or keys 1, 2, 3, 4 and 5. Each view has a header row with its name, a search or filter box where it applies, and a count on the right.

| View | Shows |
|---|---|
| Home | Totals for your collections (cards owned, value, collections, decks), Scan cards, Search and Import buttons, offers waiting in your Inbox, and your recent scans |
| Card search | Search results as a grid of card pictures, binder pages or a list, with prices and owned counts; see [Card search](/about/card-search) |
| Collection | The open collection, in four tabs: Cards (a grid of card pictures, binder pages or a list), Completion, Missing and Statistics; see [Collections](/about/collections), [Set completion](/about/set-completion) and [Prices and statistics](/about/prices-and-statistics) |
| Deck | The open deck, in seven tabs: Cards (the format check and the cards by zone and group as a list, text, stacks or grid), Add (Quick add and a card search), Ownership, Statistics, Playtest, Description and History; see [Decks](/about/decks) |
| Trade | Saved trades: You give and You get with their searches, the balance bar and wishlist matches; see [Wishlists and trading](/about/wishlists-and-trading) |
| Proxies | The print list with sheet settings, preview and exports (Print tab), and the card maker (Card maker tab); see [Proxies and the card maker](/about/proxies) |

Click a row to select it; its details appear in the Card panel. Up and Down select the previous or next row. The About guide and the card page also open in the work area and close with **Close**, **Back** or Esc. The About guide also closes when you open a collection, deck, card or view, or select a card in a panel.

## Card page

The card page shows one card in full. It opens from **Card page** in a right-click menu, by tapping a card on a phone, and by tapping a card in the scanner.

- A banner with the card's art and a **Back** button.
- Name, mana cost, type line, power and toughness, and the rules text.
- Where you have it: each collection with its copies (and proxies), and each wishlist that wants it.
- **Versions**: every printing of the card with set, number, rarity and year, and the market price for Normal, Foil and Etched where the printing exists in that finish. The card shown is first and highlighted; tapping another printing shows it.
- **Rulings**: the official rulings for the card with their dates, or "No rulings".
- **Price history**: the printing's saved prices as a line chart per finish, with **Show table** (see [Prices and statistics](/about/prices-and-statistics)).
- A round actions button at the bottom right: **Add to name...** (where cards go, opening the printing chooser), Add as proxy, Add to wishlist and Scan cards.

### Moving and arranging panels

Panels sit in three dock areas (left, right and bottom) or float above the work area.

- Drag a panel's tab onto another panel's tab row to join it as a tab.
- Drag it to the top or bottom part of a panel to stack it above or below.
- Drag it to the left or right edge of a panel to place it in a new column beside it.
- Drag it to the left, right or bottom edge of the window to dock it there.
- Drop it on the work area to make it a floating window. Move a floating window by its grip strip and resize it from any edge or corner.
- A blue rectangle shows where the panel will land.
- Dragging a floating window by its grip works the same way: over another panel or floating window, at a panel's edge or at a window edge, the blue rectangle shows where it will land, and letting go docks all of its panels there (as tabs, split beside the panel, or in the dock area). In open space the window just moves, and its edges snap to the edges of other floating windows that are within a few pixels.
- When a panel's tabs do not fit its width, they wrap onto more rows.
- Drag the line between panels to resize them, and the inner edge of a dock area to change its width or height.
- The **x** on a tab closes the panel. The Panels list on the View tab opens and closes panels.

### Workspaces

Workspaces are in the account menu (your name at the top right).

A workspace is a saved panel layout and view. Three are built in:

| Workspace | Layout |
|---|---|
| Search | Filters above Collections on the left, Card on the right, card search view |
| Collection | Collections on the left, Card on the right, Import review at the bottom, collection view |
| Deck building (the default) | Filters and Decks above Collections on the left, Deck list above Card on the right, card search view |

**Save workspace...** saves the current layout under a name (saving with an existing name replaces it). **Manage workspaces...** lists all workspaces with **Use** and, for saved ones, **Delete**. **Reset panels** returns to the current built-in workspace, or Deck building. Built-in names cannot be used for saved workspaces.

## Phone layout

Below 900 pixels wide, and always in the Android app, the title bar, menus, mode tabs, panels and status bar are replaced by:

- A top bar with the deck name, "Card", "Scan" or "Mana Vault", in the Android app the sync button (see [Android app](/about/android-app)), **Filters** in the collection, deck and trade views, **Trades** with a count when trades wait for your answer, an **Inbox** button with a count when offers are waiting, and the **Menu** button at the top right.
- The current view, filling the screen. Phones open on Home. The card search adds a **Filters** button under the search box.
- A bottom tab bar: **Home**, **Search**, **Collection**, **Decks**, **Trade**, **Proxies** and **Scan**. Search is card search. Decks shows the open deck, with the deck switcher at the top. Scan opens the camera scanner in place of the view (see [Scanning cards](/about/scanning-cards)).
- Tapping a card opens its card page (except while picking rows).
- **Menu** opens a sheet with one section per menu (File, Edit, View, Help). Tapping a section opens it. The last section, **Account**, is open and holds Inbox, Change password, Devices and Sign out; the Android app adds Sync now, Notifications and Check for updates. Commands that do not apply are not shown.
- Sheets that slide up from the bottom: **Filters**, **Menu** and the scanned list in the scanner. Close a sheet with **Close**, by tapping outside it, or with Esc.
- In a collection, **Select several cards** in **Options** turns on checkboxes; tap rows to pick them and use the bar above the list to move or remove them.
- Messages appear as a short banner above the tab bar.
- Rows of tabs and buttons wrap onto more lines when they do not fit, instead of scrolling sideways.
- On card pictures, the pips and buttons follow the card layout (see Card layout below).

Panels (including the Collections panel) and workspaces are desktop only; on the phone, switch collections and decks with the switcher at the top of the view, which opens as a full sheet. Choices made on one layout are kept for the other, except the collection layout and the search layout (Grid, Binder or List), which each layout remembers on its own.

## List views

The List layout of a deck, a collection, All collections, card search and the print list sets the cards out under headings, like a printed deck list.

| Item | Use |
|---|---|
| Group by (Options) | Type, SubType, Type and Tag (decks), Rarity, Color, Color Identity, Mana Value, Set, Artist, Tag (decks) or No grouping. Kept for your account, separately for decks, collections, card search and the print list |
| Sort (Options) | Name, Mana Value, Price, Rarity or Color, within each group |
| Headings | Each group heading shows its count. A click folds the group shut or opens it; folded groups are kept for your account |
| Columns | On a wide screen the groups are set out in columns that fill the width; on a phone, one column |
| Mana cost | Shown as mana symbols |
| Menu button | The **...** button on each row opens the same menu as a right-click |

Type groups are Creatures, Planeswalkers, Battles, Instants, Sorceries, Artifacts, Enchantments, Lands and Other. SubType groups by the first subtype. Color groups are White, Blue, Black, Red, Green, Multicolor and Colorless; Color Identity groups each combination of colors by name, such as "Blue and Red". Mana Value groups go from 0 to 7+, with lands last.

## Choice lists

Every list of choices (in windows, Options, the Filters panel, the scanner and the deck) is the app's own list: click or tap the button showing the current choice, then the choice you want. Up and Down move through the list, Enter chooses and Esc closes it. Long lists have a **Find** box at the top. On a phone the list opens as a sheet with **Close**. In a window, Enter on a list button confirms the window.

## Card layout

**View, Card layout...** sets where the pips and buttons sit around every card picture. The window shows a sample card with its places:

| Place | Where |
|---|---|
| Top left, Top right, Bottom left, Bottom right | On the corners of the picture |
| Under the picture, left and right | One row under the picture |
| Second line | A row under that |
| Bottom | The last row of the card, lined up across a row of cards |
| Hidden | Not shown |

The things that can be placed:

| Item | Holds |
|---|---|
| Count and Owned | The number of copies (such as 2x) or, in card search, OWNED with every copy you own (the tooltip splits it by finish) |
| Printings | N printings in card search |
| Finish and copy details | FOIL, ETCHED and special foils, condition, language, Proxy and the number for trade |
| Status marks | Missing, Upgrade wanted, Owned and Other version owned, In deck, Printing removed, Custom |
| Finish lines | The lines under a picture that stands for more than one kind of copy (such as REGULAR 1 and FOIL 1), one per kind, to pick one. With Finish lines hidden, clicking such a picture asks which kind of copy, listing each with its finish and count |
| Price | The price, when Prices on pictures is on |
| Buttons | The add buttons (+ name, + Wishlist) or the print list count and Remove |

Drag an item to a place, or click an item and then a place; dropping it on another item puts it before that one. **Same layout everywhere** (on by default) uses one layout for every section; turned off, a section choice (Card search, Collections, Decks, Trade, Proxies) sets each on its own, starting from the current layout. **Reset to default** puts the pips in one row under the picture with the price at its right, the finish lines on the second line and the buttons at the bottom. Layouts saved before Finish lines existed show them on the second line. The layout is kept per account and used on every device.
