# Glossary

| Term | Meaning in Mana Vault |
|---|---|
| Card | A card by name, such as Lightning Bolt, across all its printings |
| Printing | One version of a card in one set, with its own set code, collector number, rarity and artwork |
| Card database | The local catalog of every printing, downloaded from Scryfall |
| Card list | The smaller copy of the card database that the Android app keeps on the phone for offline search and scanning |
| Device | A phone signed in with the Android app, listed in Devices... |
| Offline | The state of the Android app when the server cannot be reached; it works from its copy of the library |
| Sync | Sending changes made on a phone to the server, then updating the phone's copy |
| Waiting change | A change made on a phone and not yet sent to the server |
| Collection | A named place for cards you own, such as a binder, with its own rules for set completion |
| Collection entry | One printing in one finish, condition and language in a collection, with a count and a number for trade |
| Finish | Regular, foil or etched. Etched is a foil-like finish printed on some cards; it counts as foil for set completion |
| Special foil | A named kind of foil a printing is made in, such as Surge foil, Galaxy foil or Textured foil, shown in place of FOIL |
| Admin | An account that can open Administration and change settings for the whole server. The first account is the admin |
| Art Tags | Scryfall's tags for what a card's art shows, such as cat or forest; used by Art shows and `art:` |
| Oracle Tags | Scryfall's tags for what a card does, such as ramp or removal; used by Role and `role:` |
| Invite code | A one-time code from an admin that lets one person create an account when sign-up is by invite |
| Picture folder | The folder on the server where downloaded card pictures are kept |
| Server backup | A copy of the whole server's database (every account and the card database), written by Administration |
| Price history | The prices saved with each card database update, for the days they changed |
| Printings badge | The N printings mark on a card search result for a card with more than one printing |
| Total line | The last line under a picture in Grid and Binder, with the count and value of every copy of that printing |
| Condition | How worn a copy is: Mint, Near mint, Lightly played, Moderately played, Heavily played or Damaged |
| Copy details | The window that changes an entry's finish, condition, language and number for trade |
| Wishlist | A collection of cards you want. Its cards do not count as owned |
| Trade list | Every copy marked for trade in the collections you own |
| Trade | A saved list of what you give and what you get, with a name and a status: Open, Done or Cancelled |
| Counter-offer | A change to a trade sent between two accounts; it passes the turn to the other account |
| Trade binder | The public page, opened by a link without signing in, listing the cards you marked for trade |
| All collections | The switcher entry that lists the rows of every collection at once |
| Filtering | The line at the top of the Filters panel naming the view it filters |
| Price | Scryfall's price for a printing on the day of the last card database update |
| Value | Price times count, added up for a row, collection or deck |
| Currency | US dollars or euros, the unit for every price and value on screen |
| Filter tag | A narrowing of the collection list chosen by clicking a set code, rarity or Statistics bar |
| Binder layout | The collection shown as pages of nine card images |
| Grid layout | The collection shown as card pictures that fill the width, loading more while scrolling |
| Switcher | The button with the open collection's or deck's name that opens a searchable list of the others |
| Flavor name | Another name printed on some versions of a card, matched by search and imports |
| Ownership | Which deck cards you own across your collections |
| Target collection | The collection that Add to collection puts cards into, when a collection was selected last; marked Adding here in the Collections panel when it was |
| Selected last | The collection or deck clicked last in its panel or switcher, where new cards go; it is the one highlighted |
| Custom card | A card made in the card maker and saved to the card database for every account, marked Custom |
| Custom set | A set made for custom cards, with its own code, name, release date and symbol |
| Print list | The cards to print as proxies, kept with your account |
| Bleed | Extra picture around a card's cut edge, so a slightly uneven cut shows no white edge |
| MakePlayingCards | A printing service that prints uploaded card pictures; MPC for short |
| MPC Autofill | A separate website that fills a MakePlayingCards order from a card list with its own scans |
| Open collection | The collection shown in the collection view |
| Linked set | A set whose completion a collection tracks |
| Completion rule | None, Main set, Every printing or Each card name once; decides which cards a linked set needs |
| Finish rule | Any finish, Regular only, Foil only or One of each; decides which finishes count |
| Printed size | The number of numbered cards printed in a set, from Scryfall's set list |
| Picked rows | Collection rows chosen for a bulk move or remove |
| Owner | The account an item belongs to |
| Offer | A collection or deck sent to another account, waiting in their Inbox |
| Copy, Share, Transfer | The three ways to send: their own copy, one item you both edit, or moving it to them |
| Inbox | The list of offers waiting for you and offers you sent |
| Foil | The shiny finish of a printing. Regular and foil copies are counted separately |
| Deck | A named list of printings with a format, linked to the collection copies that fill them |
| Link | The tie between a deck card and the copy in a collection that fills it. A copy fills one deck card at a time |
| Missing | A deck card with no linked copy |
| Owned, link | The mark on a missing deck card when free copies of exactly its printing and finish are in your collections |
| Other version owned | The mark on a missing deck card when free copies of another printing or finish of the card are in your collections |
| Upgrade wanted | A mark on a deck card that is in the deck and owned, recording the better version wanted, such as a foil |
| Adding here | The only mark in the Collections or Decks panel on where cards go: the collection or deck that Enter and the add button put cards into |
| Reduce to 1 | Lowering a card with several copies to one copy, for copies added by accident |
| Free copy | A copy in a collection that fills no deck card |
| Proxy | A printed stand-in card, kept apart from real copies, with no value |
| Want | The number of copies a wishlist row asks for; it goes down as copies are added to collections |
| Card page | The full view of one card: art, text, versions with prices, rulings and where you own it |
| Quick mode | A scanner setting that takes the first matching printing instead of asking |
| Set filter | The scanner sets outside which a card gives a "Not in set" warning |
| Zone | Where a card sits in a deck: commander, main deck, sideboard or maybeboard |
| Maybeboard | The zone for cards being considered; not counted in the deck's size, value, ownership or legality |
| Tag | A word you give deck cards, such as Ramp, to group them |
| Quick add | The box in the deck view that adds a card by typing a count and name |
| Cover card | The card whose picture stands for a deck in the switcher |
| Legality | Whether a deck follows its format's rules |
| Token | A card that a deck's cards create during a game, listed under Tokens |
| Playtest | Drawing sample hands from a deck without changing it |
| Target zone | The zone that Add to deck puts cards into |
| Scanned list | Cards recognized by the scanner or added by name, waiting on this device to be added to a collection or deck |
| Information line | The small text at the bottom left of a card printed since 2019, with the collector number, rarity letter, set code and language |
| Open deck | The deck that Add to deck, the Deck list panel and the deck view work with |
| Format | The game type a deck is built for (Commander, Standard and so on), which the deck is checked against. Casual decks are not checked |
| Mana value | The total mana in a card's cost, used by the mv filter |
| Color identity | Every color in a card's cost and rules text, used by the id filter |
| Selected card | The row last clicked or moved to with Up and Down; its details show in the Card panel |
| Panel | A dockable window beside the work area: Filters, Collections, Decks, Card, Deck list or Import review |
| Workspace | A saved arrangement of panels and a view |
| Ribbon | The tabs of buttons under the title bar; the program's only menu |
| Context group | A ribbon group shown only while that part of the program is in use, such as Build while a deck is open |
| List button | A ribbon button with ▾ that opens a list of related commands |
| Import preview | The check of an import file that shows what would be added before anything changes |
| Backup | A JSON file with one account's own collections, decks and the card records they use |
| Session | A signed-in browser, kept for 30 days |
