# Settings and shortcuts

## Preferences

Preferences are saved for your account on the server and follow you to every browser and device.

| Setting | Choices | Default | Where to change it |
|---|---|---|---|
| Theme | Light, Dark, System | Light | View menu, View ribbon tab, phone Menu |
| Add as foil | On, Off | Off | Cards menu, Home ribbon tab, FOIL in the status bar, F |
| Target zone | Main deck, Sideboard, Commander | Main deck | Deck menu, Deck ribbon tab, Deck list panel, ZONE in the status bar, Z |
| Target collection | Any of your collections | Your first collection | Cards menu, Home ribbon tab, ADD TO in the status bar, Collections panel, C |
| Open collection | Any of your collections | Your first collection | Collection list in the collection view, Collections panel |
| Prices (currency) | US dollars, Euros | US dollars | View menu, Database ribbon tab, PRICES in the status bar, Statistics tabs |
| Collection sort | Name, Price, highest first, Price, lowest first, Quantity, Set and number | Name | Sort list above the collection's rows |
| Collection layout | List, Binder | List | List and Binder above the collection's rows, Binder layout, B |
| Ribbon layout | Any arrangement | Standard ribbon | Customize ribbon... |
| Selected ribbon tab | Any tab | Home | Click a tab |
| Panel layout | Any arrangement | Deck building workspace | Drag panels, View menu panel items |
| Workspace | Built-in or saved | Deck building | Workspace list on the ribbon, Manage workspaces... |
| Saved workspaces | Any number | None | Save workspace..., Manage workspaces... |
| Last open deck | Any deck | None | Open a deck |

System follows the device's light or dark setting and changes with it. A new version of Mana Vault resets the ribbon layout so new buttons appear; all other preferences are kept.

## Undo and redo

- Undo (Ctrl+Z) reverses the last collection or deck edit: adding a card, changing a count, removing an entry or deck card (one or many at once), moving cards between collections, Copy details, marking or unmarking for trade, adding to the wishlist, and moving a deck card between zones. Redo (Ctrl+Y or Ctrl+Shift+Z) repeats it.
- Up to 150 edits are kept. The history lasts until the page is reloaded.
- Imports, backup restores, creating, changing or deleting collections and decks, sending and accepting, card database updates, preference changes and trade calculator changes cannot be undone. A backup restore, or deleting or leaving a collection or deck, clears the history.
- An undo sets the counts back to what they were before the edit. If someone else changed the same card in the meantime, their change to that card is replaced.
- The Undo and Redo items name the edit they affect. A message confirms each one, such as "Undone: Add Sol Ring".

## Keyboard shortcuts

Shortcuts work when no text box, menu or window has focus, except the Ctrl shortcuts, which work anywhere outside a text box. **Keyboard shortcuts** in the Help menu shows this list.

### Search

| Key | Action |
|---|---|
| / | Find card (jump to the search box) |
| 1 | Card search view |
| 2 | Collection view |
| 3 | Deck view |
| 4 | Trade view |
| Up, Down | Select the previous or next row (Down also leaves the search box) |

### Adding cards

| Key | Action |
|---|---|
| Enter | Add the selected card to the collection |
| Shift+Enter | Add the selected card to the open deck |
| F | Switch Add as foil on or off |
| Z | Cycle zone (cycle the target zone) |
| C | Cycle target collection |
| W | Add to wishlist |

### Collections

| Key | Action |
|---|---|
| Ctrl+A | Select all rows (the rows the filter box shows) |
| Ctrl+click, Shift+click | Pick more rows, or a range of rows |
| Delete | Remove selected... |
| E | Copy details... |
| B | Binder layout (switch between list and binder) |
| Page Up, Page Down | Show the previous or next binder page |

### Trade

| Key | Action |
|---|---|
| T | Add to trade (you give): the selected collection row |
| G | Add to trade (you get): the selected card |

### Editing

| Key | Action |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Y | Redo |
| Ctrl+Shift+Z | Redo |

### Decks

| Key | Action |
|---|---|
| Ctrl+N | New deck... |
| Ctrl+O | Open deck... |

### General

| Key | Action |
|---|---|
| Esc | Close the window, menu, sheet or About guide, or clear the selection and the picked rows |
| Enter | Confirm the open window |

On a Mac, Cmd works in place of Ctrl.
