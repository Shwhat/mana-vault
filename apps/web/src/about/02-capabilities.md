# Capabilities

This page lists what Mana Vault does in the current version, followed by what is planned.

## Available now

### Card search

- Search every printing in the local card database by name, type line and rules text.
- Narrow results with filter syntax in the search box (type, color, color identity, rules text, set, rarity, mana value, legality) and with the Filters panel.
- Show up to 40 results per search, sorted by name and then newest printing first.
- Show a card's image, mana cost, rules text, printing details and how many copies you own in the Card panel.

### Collection

- Add any printing as a regular or foil copy with one click, Enter or a double-click.
- Change counts with plus and minus buttons, and remove entries.
- Filter the collection list by card or set name.
- Import a collection CSV (Moxfield, Archidekt and similar exports) with a preview before anything is added.
- Export the collection as a Moxfield-compatible CSV.

### Decks

- Create decks with a name, a format and a mode: Normal (any printing counts) or Theme (the exact printing is kept).
- Add cards to the main deck, sideboard or commander zone, change counts, move cards between zones and remove cards.
- Import decklists as text (Moxfield, Arena and MTGO style) or CSV, with a preview.
- Export decks as text or CSV.

### Editing

- Undo and redo collection and deck edits, up to 150 steps per session.

### Card database

- Update the local card database from Scryfall on demand, and on a schedule when the server is set up for it.
- Show the number of printings and the date of the last update in the status bar.

### Scanning

- Read a card name from the phone or computer camera, or from a photo, and search for it.

### Backups

- Download a backup of the collection, all decks and the card records they use.
- Check a backup before restoring it, then replace the collection and decks with it.

### Accounts

- Sign in with a user name and password. New accounts can be turned off by the server owner.
- Change your password, which signs out your other devices.
- Keep theme, ribbon, panel layout and workspace choices per account.

### Interface

- Desktop layout with menu bar, ribbon, dockable panels, saved workspaces, status bar and light, dark or system theme.
- Phone layout with bottom tabs, full-screen sheets and an installable home screen app.
- A built-in About guide (this guide).
