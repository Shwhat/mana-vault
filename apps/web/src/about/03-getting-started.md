# Getting started

This page covers the first visit, loading the card database and adding the first cards and deck.

## First sign-in

1. Open Mana Vault in a browser. Visitors who are not signed in see the sign-in page.
2. Choose **Create account**, enter a user name and a password (at least 8 characters, or the minimum the admin set) twice, and choose **Create account**. When sign-up is by invite code, also enter the code the admin gave you. When sign-up is closed, only **Sign in** is shown; ask an admin for an account.
3. Mana Vault opens in the card search with the Deck building workspace. Your account starts with an empty collection named Main collection.

## First run

The first account created on a new server is its admin. Signing in to it opens **Setup** in Administration: download the card database, choose the picture sizes to keep on the server (each with its estimated download size) and the picture folder. Every step can be skipped with **Skip for now** and changed later in Administration (see [Administration](/about/administration)). A server updated from 0.11.0 or earlier makes its oldest account the admin and opens Setup once for it.

## Load the card database

A new server starts with an empty card database. Search, imports and decks all need it. The admin loads it in Setup, or:

1. Open the **View** ribbon tab (admins only).
2. Choose **Update card database**. The status bar shows "Updating card database" while it runs. The first update downloads the full catalog and can take several minutes.
3. When it finishes, the status bar shows the number of printings and a confirmation message.

## Add cards you own

Cards go into the collection or deck selected last with one click in its panel or switcher (a double click opens it), shown as ADDING TO in the status bar and as **Adding here** in the panel. To keep cards in more than one place, use **New collection...** on the Collection ribbon tab; see [Collections](/about/collections).

1. Type part of a card name in the search box (press **/** to jump there).
2. Click a result to select it. Its details appear in the Card panel.
3. Press **Enter**, choose **+ collection name** under the card, or double-click it. The printing chooser opens with the printing shown already selected; press **Enter** again to add one copy, or pick another printing or finish first. A card made in only one printing and one finish is added at once.
4. To start the chooser on the foil finish, turn on **Add as foil** (the FOIL toggle in the status bar, or **F**).

## Build the first deck

1. Choose **New deck...** on the Decks ribbon tab. Enter a name, pick a format, and choose **Create deck**.
2. The new deck opens in the Deck list panel and the **Deck** ribbon tab appears.
3. Select a card in the search results and press **Shift+Enter** (or **+ Deck**) to add it to the target zone.
4. Press **3** to see the whole deck in the work area.

## Where things are

| To find | Look in |
|---|---|
| Home, search, collection and deck views | Views group of the Home ribbon tab, or keys 1, 2 and 3 |
| Your collections and set completion | Collections panel and Collection ribbon tab |
| Offers sent to you | Inbox, in the account menu |
| Imports, exports and backups | Files group of the Home ribbon tab |
| Theme, panels and workspaces | View ribbon tab |
| Your account | The account menu at the right end of the title bar |
| This guide | Help menu, **About Mana Vault** |
