## Undo and redo

- Undo (Ctrl+Z) reverses the last collection or deck edit: adding a card (and the wishlist wants it lowered), changing a count, removing an entry or deck card (one or many at once), moving cards between collections, Copy details, marking or unmarking for trade, adding to the wishlist, moving a deck card between zones, linking copies to a deck card, and adding a scanned list (one step for the whole list, including the deck links), tags on deck cards, Edit as text, and completing a trade. Redo (Ctrl+Y or Ctrl+Shift+Z) repeats it.
- Up to 150 edits are kept. The history lasts until the page is reloaded.
- Imports, backup restores, creating, changing or deleting collections and decks, sending and accepting, card database updates, preference changes, changes to a trade's lines, and accepting a trade from another account cannot be undone. A backup restore, or deleting or leaving a collection or deck, clears the history.
- An undo sets the counts back to what they were before the edit. If someone else changed the same card in the meantime, their change to that card is replaced.
- The Undo and Redo items name the edit they affect. A message confirms each one, such as "Undone: Add Sol Ring".

## Keyboard shortcuts

Shortcuts work when no text box, menu or window has focus, except the Ctrl shortcuts, which work anywhere outside a text box. **Keyboard shortcuts** in the Help menu shows this list.

### Search

| Key | Action |
|---|---|
| / | Find card (jump to the search box) |
| 1 | Card search view |
| 2 | Collection view |
| 3 | Deck view |
| 4 | Trade view |
| 5 | Proxies view |
| Up, Down | Select the previous or next row (Down also leaves the search box) |

### Adding cards

| Key | Action |
|---|---|
| Enter | Add the selected card to the collection or deck selected last |
| Shift+Enter | Add the selected card to the open deck |
| F | Switch Add as foil on or off |
| Z | Cycle zone (cycle the target zone: Main deck, Sideboard, Commander, Maybeboard) |
| C | Cycle target collection |
| W | Add to wishlist |

### Collections

| Key | Action |
|---|---|
| Ctrl+A | Select all rows (the rows the filter box shows) |
| Ctrl+click, Shift+click | Pick more rows, or a range of rows |
| Delete | Remove selected... |
| E | Copy details... |
| B | Binder layout (switch between binder and grid) |
| Page Up, Page Down | Show the previous or next binder page |

### Trade

| Key | Action |
|---|---|
| T | Add to trade (you give): the selected collection row goes into the open trade (a new one when none is open) |
| G | Add to trade (you get): the selected card goes into the open trade |

### Editing

| Key | Action |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Y | Redo |
| Ctrl+Shift+Z | Redo |

### Decks

| Key | Action |
|---|---|
| Ctrl+N | New deck... |
| Ctrl+O | Open deck... |
| Q | Go to Quick add in the open deck |

In the collection and deck switchers, type to find, Up and Down move, Enter opens and Esc closes the list.

### General

| Key | Action |
|---|---|
| Esc | Close the window, menu, sheet, scanner or About guide, or clear the selection and the picked rows |
| Enter | Confirm the open window |

On a Mac, Cmd works in place of Ctrl.
